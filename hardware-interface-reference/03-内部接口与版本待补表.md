# 内部接口与版本待补表

用户已确认涉及项目具体定义；目前未取得下列定义。此表用于补充参考库，不要求为编写文档虚构实际器件。

| 条目 | 已知/当前处理 | 需要补充的最小资料 | 未补前的边界 |
| --- | --- | --- | --- |
| TBus | 保留原名，不解释全称 | 全称、内部规范编号/版本、用途、信号表、允许拓扑 | 不推断引脚/电气类别 |
| 背板高速 IDX1 | 独立资料入口 | 规范编号/版本、板卡/槽位端点、连接器针位视图、lane/旁带定义、电气与时钟规则 | 1 不代表单 lane |
| 背板高速 IDX2 | 独立资料入口 | 同上，并说明与 IDX1 的关系及是否允许互连 | 2 不代表双 lane，不复用 IDX1 接线 |
| 背板高速 UDX | 独立资料入口 | 规范编号/版本、业务/方向、针位/lane/旁带、允许拓扑和电气验收要求 | 不从 U 推断上下行 |
| 204X | JESD204x 仅为条件分支 | 正式全称；若为 JESD204，给 A/B/C 等版本、编码、Subclass 和链路参数表 | 尚未锁定 JESD204 或版本 |
| DDRx | 分代/分组规则入口 | 实际代际、控制器/IP、颗粒组织、Rank/位宽、PCB 指南 | 不提供跨代统一落板参数 |
| ETH / XGE | 先选接口层/介质 | 速率、MAC–PHY/串行/铜缆/光纤/背板链路段、PHY/模块 | 不将所有 Ethernet 接口当同一组 pin |
| eSPI | 本稿以 Intel Enhanced SPI 为范围 | 确认项目名称是否指该规范或芯片厂商其他增强 SPI | 同名接口不能互套 |

每份内部资料建议保留：文件名/编号、版本/日期、提供者、适用产品/器件/模式、页码/表号、原始信号/方向/驱动类型、供电/掉电状态、拓扑、针位视图、参数限值和验收方法。

补齐后更新对应接口文档的规则附录 的 Q 项、R 规则和来源；只解除已被证据覆盖的缺口。未执行仿真/实测的结果仍保持 NOT_CHECKED。
