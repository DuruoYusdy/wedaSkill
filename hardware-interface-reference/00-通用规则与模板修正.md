# 通用规则与模板修正

本库按用户清单逐项维护，保留必选入口、五步流程和五部分输出。协议不能因为共用章节就共用引脚、拓扑或外围参数。当前所有条目为 draft；未执行实际器件匹配、EDA 修改、PCB 仿真或硬件测试。

## 原示例需要修正的规则

| 原示例问题 | 本库采用的处理 |
| --- | --- |
| 3.3V/1.8V 的示例与结论相互写反 | 不从名义供电直接宣告兼容；逐方向核对门限和输入范围，资料不足 UNKNOWN |
| CS 的箭头写为 Master←Slave，但文字说主机输出 | 普通 SPI CS 为 Controller→Target；极性查手册 |
| M 前缀一律输出、SDI 的 S 一律表示 Slave | MOSI/MISO 依控制器角色；SDI/SDO 表示相对各器件的数据输入/输出 |
| SIMO/SOMI 释义混淆 | SIMO=Slave In Master Out；SOMI=Slave Out Master In；仍核对实际控制器 |
| 没有 n 前缀即高有效 | n/#/横线仅提示低有效；无前缀不证明高有效 |
| 不同 VCC 一定转换，单电源数字电平一定等于 VCC | 核对实际 IO bank、标准、容限、DC/AC 和供电状态；供电范围不是实际配置 |
| 所有电平转换统一优先 TXS0108E | 按开漏、推挽、双向、PHY/SerDes、模拟分支选择；TXS 仅在其限制内可列候选 |
| 74HC125/126 可无条件用于高速三态/电平处理 | 必须核对具体系列的门限、供电、带宽、OE/掉电和延迟，不能按“74HC”名称泛化 |
| 多从机必加缓冲、固定降速百分比 | 依据实际驱动、负载、拓扑和往返时序选择，节点数不独立决定 |
| Stub、差长、串阻、去耦统一固定值 | 依据边沿、介质、负载、时序和器件设计；必要时用计算/仿真/实测确认 |
| GPIO25/26 等被写成某厂商固定 SPI 引脚 | 不保留脱离确切型号/封装/pin mux 的固定 GPIO 号 |

## 通用电气判断

单端推挽的直流逻辑必要条件为 VOH,min ≥ VIH,min、VOL,max ≤ VIL,max，按相同工作条件并保留设计噪声余量。高电平裕量可记 NMH=VOH,min−VIH,min，低电平裕量 NML=VIL,max−VOL,max。还需检查推荐输入范围、绝对最大值、钳位电流、输出负载、掉电容限及动态时序。绝对最大值不能当正常工作设计点。

开漏检查共同上拉电源容限、等效上拉、灌电流、VOL 与上升时间；I2C 的 RC 上拉计算见 [IIC 规则附录](IIC.md#规则与要求)，不自动替代 SMBus、MDIO 或其他网络的具体电气要求。

差分数字/SerDes 检查差分摆幅、共模、接收能力、终端与耦合；模拟 RF 另检查满量程、阻抗、噪声和线性度。USB、Ethernet MDI、CAN/RS 总线不使用 GPIO 转换器代替其 PHY/收发器。所引 TXS0108E 手册有供电、负载和波形限制；自动方向不等于任意接口自动兼容。

来源：[TI Logic Guide](https://www.ti.com/lit/sg/sdyu001aa/sdyu001aa.pdf)、[TXS0108E datasheet](https://www.ti.com/lit/ds/symlink/txs0108e.pdf)、[TXU0304 固定方向器件入口](https://www.ti.com/product/TXU0304)。具体器件的工作条件以数据手册为准，不依网页摘要的混杂参数选型。

## 输出与证据

运行输出顺序固定：电平判断结论 → 信号匹配结论/矩阵 → ASCII 图 → 风险检查 → 补充建议。输入不足时按入口要求等待，不能用例图冒充本次匹配。

矩阵每行记录连接ID、场景、标准信号、两端真实器件/原名/引脚号/方向、网络和共享成员、中间功能及连接器视图、供电域、规则/来源定位、电气判断与连接状态。没有实际引脚号就写待补，不能猜。

证据状态：verified-source / user-provided / assumption / unresolved。检查状态：PASS / FAIL / UNKNOWN / NOT_APPLICABLE / NOT_CHECKED。通用规则的来源核验、某器件的适用性和硬件实测是三件独立的事。

## 受控名称与覆盖边界

TBus、IDX1、IDX2、UDX：用户确认涉及项目具体定义，但未提供全称、协议、版本或引脚表。保留采集入口和草稿，不从拼写推断技术细节。

204X：保留原始名称，JESD204x 只作为条件分支；用户回复“是”不足以确认具体内部定义、JESD204 版本或 Subclass。ETH/XGE 必须进一步选定接口层与介质；eCPRI 是业务承载协议，不是独立电气引脚集。
